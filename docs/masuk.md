# Masuk

[← Indeks dokumentasi](README.md) · `/login` · Akses dan keamanan akun

Gunakan email dan password dari akun yang sudah disetujui HR.

- Setelah berhasil masuk, DexaTrack membuka Dashboard untuk admin HR atau Beranda untuk karyawan.
- Gunakan [Daftar akun](daftar-akun.md) untuk mendaftar mandiri atau [Lupa password](lupa-password.md) untuk meminta tautan pemulihan.
